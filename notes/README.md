# Notes

Plans, decisions and Claude Code session notes for the 3D model editor. Plain Markdown —
read here on GitHub, or open this `notes/` folder as a vault in Obsidian.

- `Sessions/` — one note per Claude Code session on this project, written automatically.
- Anything else — plans and notes; add or edit freely.

**This repository is public.** Never put keys, passwords, customer details or anything you
would not want the world to read in these notes.

Lester's Mac syncs this folder every 15 minutes: it commits notes changes, pulls, and pushes
to `main`. If two people change the same lines between syncs, the sync stops and the clash is
resolved by hand.
